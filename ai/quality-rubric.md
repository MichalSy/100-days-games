# Quality Rubric

Score each daily game after real browser/mobile testing.

- Playability: 0–5
- Mobile UX: 0–5 (portrait phone usability by default: readable 390x844 layout, 44px+ touch targets, no forced landscape unless justified with an orientation gate)
- Menu/tutorial clarity: 0–5
- Visual polish: 0–5 (generated images inspected; sprites are properly cut out, face/rotate correctly during movement, and remain readable at final size)
- Prompt page consistency: 0–5 (`prompt.html` is semantic rendered HTML with the standard prompt-page style, not raw Markdown in a `<pre>`)
- Audio/feel: 0–5
- 15-minute value: 0–5
- Prompt completeness: 0–5
- One-shot success: 0–5
- Difference from recent games: 0–5
- Mode variety / 3D cadence: 0–5 (no more than three consecutive 2D games; after two 2D games, 3D is preferred; 3D/hybrid must use real depth/spatial gameplay)

A game may only publish if build/test/smoke requirements pass, regardless of subjective score.
