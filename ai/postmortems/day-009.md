# Day 009 Postmortem — Tsuki Shadow Puppet Troupe

## QA summary

Day 009 was reviewed against the generated prompt using only the Day 009 prompt, Day 009 app/release files, release metadata, and local browser/runtime checks. Previous game implementation source was not opened, copied, diffed, grepped, or adapted during this QA pass.

## What worked

- The title/menu exposes the Day 009 badge, hybrid badge, `/tsuki/` route, best-score fields, prompt link, large Start button, and visible tutorial.
- Tutorial copy covers objective, puppet rods, poses, depth lanes, cue timing, hazards, Moon Freeze, and pause/restart.
- Gameplay starts from `/tsuki/` without console or request errors.
- Puppet selection, rod dragging, keyboard movement, pose controls, Far/Near depth controls, Cue Scene feedback, pause/resume, restart, and prompt navigation were smoke-tested.
- The game implements meaningful hybrid depth behavior: near/mid/far lanes have different scale, opacity, blur, timing offset, target requirements, hazards, and visual parallax.
- Prompt markdown was copied exactly to both release prompt paths.
- Prompt HTML has the expected title/h1, headings, lists, back link, and is not a raw Markdown `<pre>` dump; no `ul > p` or `ol > p` malformed nodes were found.
