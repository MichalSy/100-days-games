# Day 042 Postmortem — Kabuto Cedar Canopy Climber

## Summary

Day 042 ships `Kabuto Cedar Canopy Climber`, a mobile-first 3D vertical climbing arcade game on the public route `/kabuto/`. The design deliberately breaks the recent 2D streak with a bright portrait 3D cedar-trunk climb: orbit lanes, ordered sap beads, branch leaps, grip/haze pressure, firefly charms, WebAudio cues, and a Canopy Focus preview mechanic.

## Asset QA

Generated Imagegen2 assets were inspected before integration:

- Kabuto hero: acceptable silhouette, readable beetle body and shell, no text/watermark, suitable as helper thumbnail.
- Cedar canopy background: bright portrait forest, crop-safe, enough open central space behind the 3D trunk.
- Pieces sheet: fake checkerboard was alpha-cleaned/neutralized; individual bark, moss, sap, charm, leaf, hazard, reach-ring, and bell motifs remain readable enough for source archive/runtime reference.
- Icon sheet: readable gameplay affordance icons without text/watermark.

Runtime uses the 3D geometry for the main playable objects, with generated art used for atmosphere/helper/source visual identity.

## Fixes made during QA

- Added an explicit Combo HUD chip so all prompt-required HUD fields are visible.
- Fixed route script compatibility with the implemented HTML IDs and overlay classes.
- Wired `data-action="wings"` to the Fan Wings mechanic so the visible control has a real state effect.
- Moved Start actions higher in the tutorial modal for first-viewport mobile usability.
- Reworked the 390x844 portrait layout to keep HUD, commission, stage, helper, and every primary control visible without body scrolling.
- Vendored both `three.module.min.js` and `three.core.min.js` into app/release/alias paths to avoid Three.js module 404s.

## Notes for future runs

- For 3D mobile games with many named controls, a 3-column mobile control grid is necessary; 2 columns consumes too much vertical space.
- Keep all required live HUD chips visible on mobile; hiding lower-priority chips with `nth-child` can accidentally hide prompt-required state like `Next sap`, `Risk`, `Focus`, or `Time`.
- When a controller recovers from an implementation mismatch, copy the chosen app HTML/CSS/JS back into both immutable release and public alias before route smoke.
