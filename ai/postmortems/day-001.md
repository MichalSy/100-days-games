# Day 001 postmortem — Koi Lantern Drift

## What worked

- Implemented the archived Day 001 prompt as a self-contained static canvas game with title, tutorial, HUD, pause, restart, game-over, best score, combo tiers, current shifts, spark waves, hazards, Festival Bloom at 1200, desktop keyboard controls, and mobile drag/focus controls.
- Imagegen2 asset generation was available. Source outputs were archived under `release/games/001/assets/source/`, with optimized playable copies under `release/games/001/assets/`.
- The prompt was copied to `release/games/001/prompt.md` and rendered as `release/games/001/prompt.html`.

## Issues

- No emergency art fallback was required because the real Imagegen2 attempts succeeded.
- The repository had no previous app examples under `apps/`, so Day 001 uses a lightweight vanilla HTML/CSS/JS structure.

## Improvements for future days

- Add a reusable daily static-game scaffold that writes both `/games/NNN/` archival files and `/NNN/` playable route files.
- Extend validation to explicitly check per-day assets, screenshots, prompt HTML, and route aliases instead of relying on manual smoke checks.
